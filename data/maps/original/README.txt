The six levels of the original Fire Power (Silent Software / MicroIllusions, 1987):
their layouts only (ground, roads, trees, buildings, guns, where the bases stand),
converted to OpenFirePower map files by tools/ofp_maps.py. No graphics, sounds or
code from the original are in this folder or the project: the game draws and
plays them with its own.

The game lists them under WORLD: ORIGINAL (and REMASTER), as "Original P1 t1" and
so on. To convert them again from a disk: python3 tools/ofp_maps.py FirePower.adf
