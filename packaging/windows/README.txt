OpenFP for Windows
=========================

Classic and enhanced tank combat. Free software (MIT licence).

Windows x64

For the MSI, install OpenFP and launch it from the Start menu. The installer
adds the game to Windows Installed Apps. For the portable build, keep the whole
folder together and start openfirepower.exe.

These builds are unsigned.

Player 1 uses the arrow keys, period to fire, and comma for mines.
Player 2 uses W A S D, Space or Left Alt to fire, and Left Shift or E for mines.
Escape opens the pause menu during a match.
Game pads work too. F1 in the map editor lists its keys.

Online: NETWORK GAME -> QUICK MATCH or FIND SERVERS; or a server's address under SERVER,
then JOIN (private servers too). Start with any button: pick or make your profile. Up to four: each presses FIRE on their own pad or keys.
The server list and match history: https://openfp.retrocs.org/

Your settings, maps, replays and music are kept in %APPDATA%\OpenFirePower\
(paste that into Explorer's address bar to open it).
