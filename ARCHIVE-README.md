# OpenFirePower 0.1 source archive

Start with [README.md](README.md) for instructions to build the Linux, macOS,
Windows and AmigaOS clients, the Apple TV preview and the Linux dedicated server.

The archive includes the game and server source, built-in maps and artwork,
soundtracks, generated Amiga assets, vendored libraries, tests, packaging
scripts and the PHP website. See [CREDITS.md](CREDITS.md) for the asset and
library licenses.

Build the clients with the toolchains listed in the README. Build outputs,
local configurations and files imported from original game disks are excluded.
The [Amiga port guide](docs/PORTING.md) covers testing with your own AmigaOS
installation. The [website guide](public-website/README.md) covers
installing the site alongside an existing server listing and database.
