# OpenFP 0.1

OpenFP is an open-source tank combat game inspired by the 1987 Fire Power.
Classic preserves the original style of play; seven enhanced worlds add their
own settings, vehicles, weather and battlefield features.

* Desktop clients for macOS, Windows and Linux, plus a native 16-colour AmigaOS
  client for 68040/68060 systems.
* Local split screen, dedicated-server network matches with up to eight tanks
  including computer players, team selection, chat and controller-friendly menus.
* Classic, Capture the Flag, Conquest and other enhanced match modes, with
  configurable lives and match lengths up to 30 minutes.
* Map editors with team areas, object categories, playability checks and recovery
  drafts; replays, training and field challenges.
* World soundtracks, scrolling credits, improved combat effects and nearby radar.

Linux desktop clients and the dedicated server are separate portable downloads;
the server archive includes its command-line tools. Native runtime checks remain separate from automated build verification;
consult the build records and platform checklists. Apple TV is a preview and is
not included in this release. A separate higher-colour Amiga edition and Desert
Co-op remain deferred.

See README.md for installation/build instructions, CREDITS.md and
