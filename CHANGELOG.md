# Changelog

## 0.1 — First release

### Tank combat

- Classic gameplay inspired by Fire Power (1987), with flag capture, prisoner
  rescue, destructible bases, garages, turrets, gates and mines.
- Eight worlds: Classic, Moon Base, Winter, Desert, Jungle, Swamp, Volcano and
  Wasteland, with world-specific artwork, soundtracks and vehicles.
- Eight modes: Classic, Capture the Flag, Conquest, Hardpoint, Team Deathmatch,
  Kill Confirmed, Annihilation and Warlord.
- Enhanced-world weather, day and night lighting, ice, oil spills and optional
  power-ups. Classic retains its original handling and three-tank selection.
- Nearby radar with flags and checkpoints, combat effects and a laughing-skull
  tank-loss animation.

### Players and online games

- macOS, Windows and Linux desktop clients, plus a native 16-colour AmigaOS
  client for 68040 and 68060 systems.
- Local split screen for up to four desktop players or two Amiga players.
- Dedicated-server network matches for up to eight tanks including bots, with
  team selection, ready status, chat, host/admin roles and team leaders.
- Server-run bot decisions, spectators, match rejoining, public server listings
  and private connections.
- Profiles, configurable keyboard layouts, controllers and on-screen text entry.
- Configurable tank lives and match lengths up to 30 minutes; tactical team
  orders in enhanced team modes.

### Tools and community

- Map editors with object categories, team areas, metadata, overview navigation,
  playability checks and recovery drafts.
- Built-in maps and a community map gallery with sharing and previews.
- Match replays, training, field challenges, controller diagnostics and benchmark.
- Dedicated-server configuration, statistics and service installation tools.
- Public website with screenshots, map gallery, match history, leaderboards,
  build guides and tagged-release downloads.
- Release automation for GitHub and optional Aminet submission, including
  source archives, installers and checksums.
